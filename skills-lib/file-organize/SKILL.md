# 文件整理与归档

整理杂乱目录、批量重命名、去重或设计目录结构时使用（办公/个人资料通用）。

## 步骤

1. 先盘点不动手：按类型/大小/修改时间统计，列出文件清单与占用。
2. 设计目标结构：按「类型/日期/项目/用途」选主维度，层级 ≤ 3 层，命名统一（如 `2026-08-21_报告_v2.pdf`）。
3. 执行前给出方案让用户确认，然后：
   - 批量重命名：规则先行（去空格、补日期前缀、统一大小写），用脚本执行并保留原文件名映射表；
   - 去重：按内容哈希（md5/sha256）识别重复文件，只列清单不自动删除；
   - 归档：旧文件移入 `archive/2026/` 之类，压缩大目录。
4. 收尾：更新映射表（原名 → 新名），关键目录放一个 `说明.txt` 记录规则。

## 检查点

- 任何删除/覆盖动作先给清单并等确认，默认只「移动」不「删除」；
- 不整理系统目录/程序目录，只处理用户指定的范围。

## 输出

「盘点结果 → 目录方案 → 执行脚本 → 变更映射表」。
