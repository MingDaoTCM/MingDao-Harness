# 安全审计

审查代码/依赖/配置的安全风险时使用。

## 步骤

1. 列出攻击面：外部输入入口、网络请求、文件读写、命令执行、认证与密钥。
2. 逐类检查：
   - 注入：SQL/命令/路径注入，用户输入是否拼接进查询或 shell；
   - 密钥：硬编码 key/token/password（`grep -rE 'sk-[A-Za-z0-9]{20,}|password\s*=' .`）；
   - 依赖：已知漏洞版本、不必要的运行时依赖；
   - 文件与权限：路径穿越、敏感文件权限（600）、上传校验；
   - 传输与加密：明文 HTTP 传敏感数据、弱哈希（MD5/SHA1 用于口令）。
3. 按「严重/高/中/低」分级，每项给出复现路径与修复方案。

## 检查点

- 只审计不直接修改，修复等用户确认（紧急项明确标出）；
- 不把密钥内容写进输出，发现时用脱敏形式提示。

## 输出

「风险清单表格（级别/位置/问题/修复）+ 总体结论」。
