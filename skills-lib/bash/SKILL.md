# Bash 脚本编写

写 shell 脚本或复杂的单行命令时使用。

## 规则

1. 开头固定：`#!/usr/bin/env bash` 与 `set -euo pipefail`（有意容忍错误处显式 `|| true`）。
2. 变量引用加双引号 `"$var"`，避免分词与通配展开；路径含空格要安全处理。
3. 用 `[[ ]]` 测试、`$(...)` 命令替换；不用已废弃的反引号。
4. 循环处理文件名优先 `find -print0 | while read -r -d ''`，避免空格文件名问题。
5. 长脚本拆函数；用户输入先校验（非空、格式、范围）。

## 检查点

- 不把 `rm -rf "$dir"` 的危险变量未校验就执行；
- 给出可移植性说明（bash 4+ / GNU coreutils 差异处注明）；
- 改动后附运行方式与预期输出。

## 输出

脚本 + 每段作用注释 + 风险点说明。
