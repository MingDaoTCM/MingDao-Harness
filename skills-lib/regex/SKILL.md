# 正则表达式

编写、调试或优化正则时使用。

## 步骤

1. 明确目标字符串样例（含边界与反例），先列 3–5 个正例和反例。
2. 选择风格：grep/awk 用 POSIX ERE，Python/JS 用 PCRE 风格，注明方言差异。
3. 逐步构造：锚点（^ $ \b）→ 字符类 → 量词 → 分组/捕获，能不用回溯就不用。
4. 用测试样例逐条验证；拿不准的边界（空串、换行、Unicode）单独测。

## 检查点

- 警惕灾难性回溯（嵌套量词如 `(a+)+`），给出安全替代写法；
- 明确是否区分大小写、是否跨行匹配（m/s 标志）；
- 替换场景注意捕获组顺序与 `$1` 含义。

## 输出

「正则 + 逐段解释 + 正反例测试结果 + 方言/标志说明」。
