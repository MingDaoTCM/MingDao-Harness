# 数据分析

对 CSV / Excel / 日志等数据做统计、聚合、洞察或可视化建议时使用。

## 步骤

1. 先探数据：文件格式、行数、字段与类型、缺失值比例（head + 统计摘要）。
2. 明确分析目标（趋势/对比/分布/异常），再选方法，避免无目的统计。
3. 计算：先聚合（分组求和/均值/分位数），再交叉对比；注意脏数据（空值、单位不一致）。
4. 图表建议：趋势→折线、占比→饼/堆叠条、分布→直方图、相关→散点。
5. 结论：每条数字结论注明口径（样本量、时间范围）。

## 检查点

- 不编造数据；算不了就说缺什么；
- 大文件流式处理，避免一次性载入内存（可用 awk/sort 预聚合）。

## 输出

「数据概览 → 关键发现（数字+口径）→ 图表建议 → 结论与行动建议」。
