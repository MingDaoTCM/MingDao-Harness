# README 写作

新建 README 或重写项目首页文档时使用。

## 结构

1. 项目名 + 一句话定位（解决什么问题、给谁用）。
2. 特色列表：3–6 条最打动人心的亮点，不堆功能。
3. 快速开始：安装 → 最小示例，5 分钟内跑通，命令真实可执行。
4. 配置与常见用法、文档链接、贡献方式、许可证。
5. 徽章与截图酌情添加；中文项目注意中英文间距与排版。

## 检查点

- 每个命令都实际验证过；版本号/链接与仓库一致；
- 避免大段空话（「强大、易用」要有具体支撑）；长度以「读完能上手」为准。

## 输出

Markdown 全文 + 一句修改说明。
