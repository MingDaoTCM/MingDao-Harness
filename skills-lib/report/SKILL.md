# 周报与汇报写作

写周报、月报、阶段总结或向上汇报材料时使用。

## 规则

1. 结构：本周成果（先说结论）→ 数据支撑 → 问题与风险 → 下周计划，篇幅按场合控制。
2. 成果写法：动词 + 事项 + 进展/结果（完成/进行中 注明百分比），重点不超过 3 条。
3. 数据优先：有数字用数字（「处理 32 个工单，平均 4 小时关闭」优于「高效处理工单」）。
4. 问题透明：说风险必带「影响 + 建议方案 + 需要的支持」，不只有抱怨。
5. 计划可验证：下周条目写成可检查的交付物，避免「继续推进」。

## 检查点

- 时间与事实核对无误；语气客观，不夸大不贬低；
- 提供「详细版（给直属上级）+ 精简版（给大群/上级的上级）」。

## 输出

两版周报 + 一句核心亮点摘要。
