# CI/CD 流水线

设计或排查持续集成/部署流水线时使用。

## 步骤

1. 确认平台（GitHub Actions / GitLab CI / Jenkins 等）与触发时机。
2. 设计流水线：构建 → 测试 → 静态检查 → 打包 → 部署，每阶段独立、可重入。
3. 环境：锁定依赖版本、缓存构建产物、密钥走平台 Secret 不写进配置。
4. 排查失败：读完整日志定位首个错误，先本地复现再改流水线，避免反复提交试错。

## 检查点

- 配置里不出现明文密钥；产物不含 .env / credentials；
- 部署步骤默认「先备份/可回滚」；生产部署加人工确认或灰度；
- 流水线尽量快：并行化、按变更路径跳过无关任务。

## 输出

「流水线配置文件 + 每阶段说明 + 本地验证方式」。
