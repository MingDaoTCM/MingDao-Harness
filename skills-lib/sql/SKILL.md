# SQL 编写与优化

写查询、审查现有 SQL、排查慢查询时使用。

## 步骤

1. 确认数据库方言（MySQL 8 / PostgreSQL / SQLite 等），先看表结构（`DESCRIBE` / `\d` 或读 schema 文件）。
2. 写查询：显式列名（避免 `SELECT *`）、JOIN 条件明确、NULL 语义想清楚。
3. 优化：先看 `EXPLAIN`，检查全表扫描、缺失索引、隐式类型转换；大分页用游标/键集分页替代深 `OFFSET`。
4. 防注入：拼接参数一律用绑定变量/参数化查询。

## 检查点

- 预估数据量级，注明是否适用；无法确认表结构时先询问用户；
- 写操作（UPDATE/DELETE）先给出 WHERE 影响范围，默认建议先 SELECT 验证；
- 迁移类语句给出回滚语句。

## 输出

「SQL 语句（带注释）+ 为什么这样写 + 性能注意点」。
