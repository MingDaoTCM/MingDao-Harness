# 数据库表结构设计

设计新表、评估现有表结构时使用。

## 步骤

1. 先梳理实体与关系：一张图（ER）胜过一段文字，明确 1:1 / 1:N / N:N。
2. 建模：主键自增或业务键（注明取舍）；外键显式声明；枚举/状态用可读字符串或注释完整。
3. 范式：满足第三范式（消除冗余），除非查询性能要求明确的冗余（注明理由）。
4. 索引：主键外所有查询条件列建索引；复合索引按「等值在前、范围在后」排序。
5. 演进：字段加注释、预留软删除字段（deleted_at）与时间戳（created_at/updated_at），迁移可回滚。

## 检查点

- 数据类型选最小够用（INT vs BIGINT、VARCHAR 长度）；
- 给出建表 DDL 与回滚 DDL 成对输出。

## 输出

「ER 描述 → DDL（含注释）→ 索引与理由 → 迁移方案」。
