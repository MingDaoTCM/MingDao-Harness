# 性能分析与调优

程序慢、内存高、接口延迟大时使用。

## 步骤

1. 先测量再优化：明确指标（延迟/吞吐/内存）与基线数据。
2. 定位瓶颈：按「CPU / IO / 网络 / 锁 / 内存」分类，用工具确认（top、profiler、日志耗时打点）。
3. 按 80/20 原则只优化热点；每次只改一处，改后立即对比基线。
4. 常见手段：缓存、批处理、索引、连接复用、异步化、减少序列化。

## 检查点

- 禁止无测量的「感觉优化」；优化前给出当前基线数字；
- 优化可能引入正确性风险（缓存一致性等），注明并验证；
- 环境因素（冷启动/网络抖动）要排除后再下结论。

## 输出

「基线 → 瓶颈定位（证据）→ 优化项（按收益排序）→ 优化后对比」。
