# 会议纪要

根据会议记录/逐字稿整理纪要时使用。

## 结构

1. 基本信息：会议主题、时间、参会人、主持人。
2. 核心结论：3–5 条，按重要性排序，写「决定了什么」而非过程复述。
3. 讨论要点：按议题分组，保留关键分歧与依据，每条 1–2 行。
4. 待办事项：任务/负责人/截止时间 三列齐全；不明确的标「待定」并注明跟进人。
5. 遗留问题：未决事项单独列出，注明下次讨论时间。

## 检查点

- 区分「事实」与「观点」，发言人模糊的信息标注为待确认；
- 用词客观中立，不加入会议外的主观评价。

## 输出

结构化 Markdown 纪要 + 一份「一句话摘要」。
