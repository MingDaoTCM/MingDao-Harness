# Markdown 排版规范

编写或规范 Markdown 文档时使用。

## 规则

1. 标题层级不跳级（# → ## → ###），同级标题风格一致；文档只有一个一级标题。
2. 列表：同类用同一种符号；有序列表序号正确；列表项之间空行按渲染器习惯处理。
3. 代码：行内代码用反引号，代码块注明语言（` ```js `）；命令附输入输出。
4. 表格：列对齐、表头简洁，长表格优先用列表替代。
5. 中文排版：中英文之间加空格、中文用全角标点、链接文字有意义（不用「点击这里」）。
6. 图片有替代文字；链接目标可访问；emoji 适度不喧宾夺主。

## 检查点

- 全文 lint：标题层级、闭合的代码块、表格列数、死链；
- 渲染目标（GitHub/本地编辑器）差异处注明。

## 输出

规范后的 Markdown 全文 + 修改点列表。
