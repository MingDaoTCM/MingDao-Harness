# 中英互译

翻译技术文档、产品文案或校对译文时使用。

## 规则

1. 先通读全文定基调：技术文档准确优先、营销文案感染力优先、界面文案简洁优先。
2. 术语统一：同一概念全文同一译法；专有名词（产品名/协议名）保留原文；首次出现可加注。
3. 避免直译：拆长句、调整语序，中文忌欧化句式（过多「的/被/进行」），英文忌中式堆砌。
4. 格式保留：Markdown 标记、代码块、链接、占位符 `{var}` 原样保留不翻译。
5. 校对：译文独立通读一遍（不看原文），检查数字/单位/日期格式本地化。

## 检查点

- 代码、命令、API 名称不翻译；歧义处标注并给出备选译法；
- 输出「译文 + 关键术语对照表 + 处理说明」。

## 输出

译文 + 术语表 + 一句校对说明。
