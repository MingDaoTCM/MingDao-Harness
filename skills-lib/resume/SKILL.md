# 简历优化

修改简历或针对岗位定制简历时使用。

## 规则

1. 结构：基本信息 → 个人优势（3 行）→ 工作/项目经历（倒序）→ 技能 → 教育，总量 1–2 页。
2. 经历写法：动词开头 + 动作 + 方法 + 可量化结果（如「将接口耗时从 800ms 降到 120ms，支撑日活 10 万」），避免职责罗列。
3. 岗位匹配：读 JD 提取关键词，经历按相关度重排，删除无关内容；一岗一版。
4. 排版：统一字体/日期格式，无错别字（逐字检查），导出 PDF 前预览。

## 检查点

- 所有数字与事实真实，不确定的向用户确认，不编造；
- 敏感信息（身份证/薪资/联系方式）按用户要求保留或脱敏。

## 输出

「修改后简历全文 + 修改点清单 + 针对该岗位的一句话匹配度分析」。
