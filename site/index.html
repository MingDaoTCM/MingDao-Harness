● 快速上手

三步完成安装；Windows 解压后双击 install.bat（自动经 winget 装 Node）。

安装

上方三平台任选一行（Gitee/GitCode 国内速度快，三平台内容一致）；无管理员权限自动装到 ~/.local/bin，仓库常驻、mingdao update 一键自更新（升级后冒烟失败自动回滚）。

配置

mingdao init 交互式配置 DeepSeek（API Key 独立存 600 权限凭证库，绝不进 config.json/仓库）；模型列表以官方 /models 线上名单为准，新模型发布自动出现。

使用

mingdao 进 TUI 对话；mingdao web 一键 WebUI（PWA 可装桌面，多任务并行）；VS Code / JetBrains 插件开箱即用；mingdao schedule add 定时任务。

● 省钱工程 ——把每一分钱算清楚

DeepSeek-V4 的缓存计价（命中 1/30 价）决定了 Harness 的核心竞争力 = 让每个请求的前缀字节稳定。MingDao Harness 围绕这一点做了系统设计。

🧊

缓存命中计价

hit/miss 拆分计费 + 命中率仪表盘，口径不一致时余量按未命中计（不漏计）。

Batch 半价批处理

×0.5

避峰调度

自动路由

pro 规划 / flash 执行，分类缓存 + 会话粘滞；系统提示跨模型字节恒定，路由翻转不破缓存前缀。

日常省 67%

精确 tokenizer
