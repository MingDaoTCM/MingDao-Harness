# Linux deb 安装形态 · 更新链路人工验收清单

> 为什么需要人工验收：`pkexec` 提权、polkit 密码框、`dpkg -i` 真实安装都要 root 与真实桌面环境，
> **CI 不能安装系统包**，所以这些步骤永远无法自动化。发布前请在真实 Linux 桌面机上逐条走一遍并记录结果。
>
> 适用版本：v0.10.0 及以后（deb 安装形态，即 `$APPIMAGE` 为空、程序在 `/opt/MingDao Harness/`）

## 0. 环境准备

```bash
# 确认是 deb 安装形态
ls -d "/opt/MingDao Harness" && echo "$APPIMAGE"   # $APPIMAGE 应为空
dpkg -l | grep -i mingdao                          # 能看到已安装版本
which pkexec                                       # 有则记录路径；没有也要记录（走手动安装分支）
```

| 项 | 期望 | 实测 | 结论 |
| --- | --- | --- | --- |
| 安装形态 | `/opt/MingDao Harness` 存在、`$APPIMAGE` 为空 | | |
| 当前版本 | 与应用内「关于/版本」一致 | | |
| `pkexec` | 记录路径或"不存在" | | |

## 1. 检查更新（正常路径）

1. 菜单/入口点「检查更新」；
2. 应用应弹「发现新版本 vX（当前 vY）」，并说明"将下载安装包并做双重校验"；
3. 点「下载并安装」。

| 项 | 期望 | 实测 | 结论 |
| --- | --- | --- | --- |
| 弹窗出现 | 有版本号、有说明 | | |
| 下载开始 | **窗口标题**出现「正在下载更新 N%」 | | |
| 进度推进 | 百分比递增，`~/.mingdao/logs/desktop.log` 每整十百分比一行 | | |
| 下载完成 | 弹出"已校验通过。安装需要管理员授权" | | |
| 日志 | 含 `stage=download`、`stage=verify`、`endpoint=sz|hk probe=xxms` | | |

## 2. 授权安装

1. 确认后应弹 **polkit 密码框**；
2. 输入密码 → 安装完成 → 弹「安装完成，重启后生效」；
3. 点「立即重启」。

| 项 | 期望 | 实测 | 结论 |
| --- | --- | --- | --- |
| polkit 弹窗 | 出现，标题为安装包相关 | | |
| 安装结果 | 弹窗提示安装完成 | | |
| 重启后版本 | `mingdao --version` 与「关于」均为新版本 | | |
| 日志 | 含 `stage=install`、安装退出码 0 | | |

## 3. 取消授权（必须验）

1. 再来一次更新流程，在 polkit 密码框点**取消**；
2. 期望：弹出「安装未完成（退出码 N）」+ **可复制的 `sudo dpkg -i <path>`** + 安装包路径 + 官网链接；
3. 用弹窗里给的命令手动安装，应成功。

| 项 | 期望 | 实测 | 结论 |
| --- | --- | --- | --- |
| 取消后的提示 | 有退出码、有可复制命令、有包路径 | | |
| 手动安装 | 命令可执行且成功 | | |

## 4. 无 `pkexec` 的机器（如能做到）

若无 `pkexec`：点「下载并安装」后应**直接**给出手动安装对话框（不进入授权步骤）。

## 5. 网络异常与坏包

| 场景 | 期望 | 实测 | 结论 |
| --- | --- | --- | --- |
| 拔网线后点检查更新 | 「检查更新失败」+「打开日志」按钮 | | |
| 下载中断（下载中拔网） | 30 秒内提示"网络停滞"/下载失败，**不是干等 5 分钟** | | |
| 人为改坏 feed 里的 sha512（一位） | 「更新包未通过校验，已删除下载文件，未安装」 | | |
| 用未签名包替换（签名不匹配） | 同上；日志含 `sha512=mismatch` 或 `签名=invalid` | | |

## 6. 线路选择

| 项 | 期望 | 实测 | 结论 |
| --- | --- | --- | --- |
| 大陆网络 | 日志 `endpoint=sz`（深圳优先） | | |
| 用 `MINGDAO_UPDATE_BASE=https://harness.mingdao.ai` 启动 | 日志 `endpoint=hk`（env 覆盖生效） | | |
| 深圳镜像某文件缺失时 | 自动回退香港并成功（日志可见回退） | | |
| 速度对比 | 记录深圳 vs 香港各自的实际 MB/s | | |
