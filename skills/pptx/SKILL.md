# PPT 生成

## 工具

- `python-pptx`：程序化生成（首次使用 `pip install python-pptx`）

## 工作流

1. **定结构**：先列大纲（每页一个核心观点），与用户确认页数。
2. **用母版布局**：优先使用默认模板的 `slide_layouts`（标题页/标题+内容），避免手工摆坐标。
3. **填充内容**：标题 ≤ 12 字；正文要点化（每条 ≤ 20 字）；图/表优先于长段落。
4. **统一风格**：字体、配色全篇一致；空白充足。
5. **校验**：生成后用 python-pptx 读回，检查页数、每页形状数量；再 `libreoffice --headless --convert-to pdf` 抽查渲染效果。

## 设计红线

- 一页一个观点；忌整页文字
- 忌花哨动画/多余装饰
- 数据页必须有来源与单位
