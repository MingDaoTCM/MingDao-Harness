# 前端设计原则

## 动手前

1. 明确**目的与受众**：这个页面要用户完成什么动作？谁在看？
2. 一个页面一个**主行动**（主按钮），层级用视觉强度表达。
3. 先静态原型后接框架：用单文件 HTML 快速验证，确认后移植。

## 设计要点

- **排版**：字号层级 ≥3 级；正文行高 1.5–1.7；文本块宽度 ≤65ch
- **配色**：一个主色 + 中性色阶；语义色只用于状态（成功/警告/错误）；正文对比度 ≥4.5:1
- **间距**：4/8 网格；分组靠留白而非边框
- **状态**：hover / focus / loading / empty / error 五态齐全
- **细节**：真实文案而非 lorem ipsum；图标统一风格；移动端先设计

## 避免"AI 味"

- ❌ 默认紫蓝渐变、玻璃拟态堆砌
- ❌ 千篇一律的三卡片 + 图标布局
- ❌ emoji 当图标、无意义动画
- ✅ 留白、克制的阴影、清晰的信息层级

## 交付

给出页面结构与关键 CSS/组件代码，说明响应式断点与可访问性处理（alt、focus、语义标签）。
