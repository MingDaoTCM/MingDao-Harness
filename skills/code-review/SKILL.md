# 代码审查

## 优先级

**正确性 > 生命周期与资源释放 > 安全 > 行为破坏 > 风格。**

一个确凿的阻塞问题，胜过一长串小意见。

## 检查清单

1. **正确性**：边界值、空值、错误路径、并发/异步竞态；每条分支都有归属。
2. **生命周期**：文件句柄、子进程、定时器、事件监听是否可逆释放；失败路径不泄漏。
3. **安全**：注入（命令/SQL/路径）、凭据硬编码、敏感信息日志。
4. **行为**：默认值、错误信息、返回结构变化是否破坏调用方。
5. **可维护**：命名是否诚实、重复是否值得抽取、注释是否解释"为什么"。

## 输出格式

```
✅ 总体判断：一句话
🔴 阻塞（必须改）：
1. …（文件:行号 + 理由 + 建议）
🟡 建议：
1. …
🟢 亮点（可选）
```
